# Архитектура и карта модулей проекта TIER-LIST-HOI4

> **Цель этого документа:** Дать любому агенту (AGY, Gemini CLI, Windsurf, Cursor) и разработчику мгновенную ориентацию в структуре проекта.  
> Все файлы строго декомпозированы по принципу **Single Responsibility** (одна ответственность на файл) и не превышают 100–300 строк.

---

## 1. Общая структура каталогов

```
TIER-LIST-HOI4/
├── index.html                 # Точка входа HTML (подключает styles.css и app.js как type="module")
├── styles.css                 # Главная точка входа стилей (14 директив @import на css/)
├── app.js                     # Главная точка входа JS (ES-модуль, инициализация и запуск приложения)
├── build.js                   # Node.js скрипт сборки в dist/
├── PROJECT_CONTEXT.md         # Единый источник правды (контекст, требования, UI/UX стандарты)
├── ARCHITECTURE.md            # Данный файл (карта модулей и назначение каждого файла)
│
├── css/                       # Модульные CSS-компоненты (14 файлов)
│   ├── variables.css          # CSS Custom Properties, цветовая палитра M3, шрифты, отступы, z-index
│   ├── header.css             # Шапка, заголовок, dev-ссылка (@redefinedtgk), тулбар (Обои, Сброс, Сохранить)
│   ├── censor.css             # Свитчер исторического режима флага Германии (цензурированный / исторический)
│   ├── matrix.css             # Разметка 2D матрицы, горизонтальный скролл, шапки стран, флаги
│   ├── tiers.css              # Левая колонка тиров (цвета, бейджи, мягкие переносы &shy;)
│   ├── cells.css              # Ячейки матрицы, трёхзонная система слотов (МП / ОБЩ / СП), ховеры
│   ├── cards.css              # Карточки механик/ошибок, динамический размер шрифта, залоченное состояние
│   ├── tray.css               # Нижний лоток колоды (Tray), слайдер зума 50%–200%, счетчики
│   ├── lightbox.css           # Модальное окно просмотра увеличенных артов карточек и флагов
│   ├── welcome.css            # Стартовый экран выбора тир-листа (Ошибки vs Фишки), бейджи карточек
│   ├── modals.css             # Базовые стили диалоговых окон, модалка подтверждения сброса, кнопка поделиться
│   ├── toasts.css             # Всплывающие уведомления (Toast), позиционирование справа вверху
│   ├── wallpaper.css          # Селектор обоев, бэкграунды и режимы отображения фона
│   └── responsive.css         # Медиа-запросы для 1440p, 1024px, 768px и мобильных разрешений
│
└── js/                        # Модульный JavaScript (ES6 Modules)
    ├── data/                  # Датасеты и статические реестры
    │   ├── countries.js       # Реестр 8 стран (Германия, СССР, США, Великобритания, Япония, Италия, Франция, Общее)
    │   ├── mistakes.js        # База карточек «Ошибки в HOI4» (30 карточек от trikiwi)
    │   ├── mechanics.js       # База карточек «Фишки и соревновательная мета» (21 карточка от Атом в леггинсах)
    │   ├── wallpapers.js      # Список доступных фоновых обоев
    │   └── tierlists.js       # Конфигурация тир-листов (ID, названия, список уровней тиров, дефолтные цвета)
    │
    └── modules/               # Модули логики и контроллеры
        ├── state.js           # Центральное реактивное состояние (активный тир-лист, расстановка, зум, история)
        ├── toast.js           # Система всплывающих тостов (уведомления об успехе/ошибках)
        ├── censor.js          # Контроллер режима флага Германии (свастика vs Железный крест + localStorage)
        ├── url.js             # Синхронизация URL search params (?list=mistakes / ?list=features)
        ├── lightbox.js        # Контроллер лайтбокса для предпросмотра артов
        ├── wallpaper.js       # Контроллер смены обоев рабочего стола
        ├── tray.js            # Контроллер колоды в лотке (скролл, зум 50-200%, счетчики свободных карт)
        ├── cards.js           # Рендерер карточек (динамический font-size, бейджи описания, залоченный статус)
        ├── dnd.js             # Drag & Drop движок (перетаскивание между лотком и зонами ячеек MP/ALL/SP)
        ├── matrix.js          # Генератор 2D матрицы, сетка ячеек, автовычисление колонок Math.ceil(sqrt(N))
        └── welcome.js         # Контроллер экрана приветствия и переключения тир-листов
```

| Лоток колоды, зум-слайдер | `css/tray.css` | `js/modules/tray.js` |
| Модалку предпросмотра арта (лайтбокс) | `css/lightbox.css` | `js/modules/lightbox.js` |

| Сборку в продакшен `dist/` | — | `build.js` |

## 3. Правила разработки для агентов
1. **Не раздувать файлы:** Не добавлять новую логику в корень `app.js` или `styles.css`. Все изменения вносятся точечно в соответствующий модуль `css/` или `js/modules/`.
2. **Точки входа:**
   - `styles.css` содержит только `@import` директивы.
   - `app.js` содержит только импорты и инициализацию жизненного цикла `initApp()`.
3. **Сборка проекта:** Команда `node build.js` копирует `index.html`, `styles.css`, `app.js`, `css/`, `js/`, `assets/` в директорию `dist/`. **Не запускать сборку без прямого указания пользователя.**
4. **Синхронизация:** При добавлении нового модуля обновлять данный `ARCHITECTURE.md` и `PROJECT_CONTEXT.md`.
