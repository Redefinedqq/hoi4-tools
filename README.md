# Матрица ошибок HOI 4 — 2D Тир-лист для мажоров

Интерактивное веб-приложение (Single Page Application) для составления двумерного тир-листа критичности игровых ошибок в **Hearts of Iron IV**.

Проект выполнен в ультра-чистой дизайн-системе **Google Material Design 3 (M3 Dark Theme)** без визуального шума и лишних плашек:
- **Динамическая квадратная сетка в ячейках:** при добавлении карточек элементы выстраиваются в сбалансированные квадраты (`1×1`, `2×1`, `2×2`, `3×3`, `4×4`) через `cols = Math.ceil(Math.sqrt(count))`.
- **Минималистичный интерфейс:**
  - Шапки стран: только флаг и краткое имя (ГЕРМАНИЯ, СССР, США, ВЕЛИКОБРИТАНИЯ, ЯПОНИЯ, ИТАЛИЯ, ФРАНЦИЯ) без вторых строк.
  - Плашки тиров: строго один центрированный заголовок (ПОЛОЖИТЕЛЬНО, БЕЗ РАЗНИЦЫ, НЕПРИЯТНЕНЬКО, СЕРЬЁЗНАЯ ОШИБКА, РУИНА).
  - Верхняя шапка: минимальная высота, заголовок и единственная кнопка «Сброс».
  - Лента ошибок: прижата к нижнему краю экрана без громоздких тулбаров; возврат карточки осуществляется простым перетаскиванием в ленту.
  - Полноэкранный модальный лайтбокс (до 85vh) по клику на карточку.
  - Компактный URL-шеринг через алгоритм LZ-String.
